# Operational Assumptions A1–A10: Code-Verified vs. Operator-Guaranteed Matrix

The unit tests (`tests/test_silhouette_full.py`) exercise the software boundary on synthetic databases. The **Code-Verified Boundary** column identifies guarantees enforced directly by Python/SQLite code in `silhouette/` and `certificates/` and covered by automated tests. The **Operator-Guaranteed Commitments** column identifies institutional, runtime, and deployment invariants that cannot be enforced purely inside the library and must be upheld by the operator hosting the trusted database.

## Key Technical Notes (`D11` Clarification)

1. **`SchemaSandbox.try_sql` (`fetchmany(1)` Projection Stepping)**: `silhouette/sandbox.py::run(..., preview=False)` calls `cur.fetchmany(1)` on the empty `SchemaSandbox` (`0` rows in every table) before returning `{"status": "success"}`. This exercises SQLite scalar expressions and projection errors (such as `abs(-9223372036854775808)`) at validation time with zero private row access.
2. **Snapshot Accounting Boundary**: Differential privacy guarantees (`ε_T ∈ {1, 2, 4, 8}` per table under row adjacency; `ε_db = 8, δ_db = 10^-6` under direct-star entity adjacency) apply to a single frozen snapshot release (`A9`). Repeated releases over mutated snapshots compose sequentially unless explicitly accounted by the operator.
3. **Direct-Star Entity-DP (`c1-entity-dp-v2-direct-star`)**: Removing legacy `entity_sql` / `unit_row` modes eliminates indirect multi-hop sensitivity amplification (`D1`). Tables outside the direct-star entity relation must be declared `"schema_only"`, verified to incur zero SQLite `SELECT` reads and emit identical `[declared_type, None, None, None, None]` stubs across neighboring databases.
4. **Unified `LocalExecutor(..., allow_cte=True)` & `deployment_prohibited` Offline Artifacts**: `silhouette/sandbox.py::restrict(..., allow_cte=True)` allows materialized query-local CTE column reads (`ephemeral_cte_read`, `db is None`) and deterministic read-only JSON scalar functions (`json_extract`, `json_valid`, `json_type`, `json_array_length`, `json_quote`), while strictly denying `json_each`, `json_tree`, persistent views, and triggers. Offline ablation artifacts (`profiles/bird_noiseless_clean/*`, `profiles/ehrsql_noiseless_nolkp/*`, `stats/mimic_demo94_patient_bins_deid.json`) are flagged `deployment_prohibited` in `manifests/custody_coverage_manifest_v10.json` and rejected by `verify_release_bundle(..., allow_non_dp=False)`.
